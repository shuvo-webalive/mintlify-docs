This area generates ABA files. Send the transactions to include, such as purchase payments, and the API builds the file from them. This area has 1 endpoint, available in all seven SDKs.

## At a glance

| Endpoint | Method | Path | What it does |
| --- | --- | --- | --- |
| [Generate an ABA file](/api-reference/aba-files/generate-an-aba-file) | <span style={{fontFamily: "var(--font-mono, monospace)", fontSize: "0.72rem", fontWeight: 700, letterSpacing: "0.02em", color: "#2563eb"}}>POST</span> | `/aba_file/generate` | Generates an ABA file from the transactions you name. |

## Before you call

Register your API credentials once when your app starts, as shown in
[Authentication](/authentication). Every SDK sample on these pages then gets its client in one line.
With cURL, send the access token in an `Authorization` header: `Authorization: Bearer $ACCESS_TOKEN`.

## Things to know

- **The body is wrapped in `aba_file`.** List the transactions under `aba_file.transactions`.
- **A transaction is named by its `id`.** The example passes a purchase payment `id`.
- **The path is singular: `/aba_file/generate`.**
