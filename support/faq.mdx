Whether you are evaluating Exsited for the first time or looking for a quick answer while you are deep in a workflow, this page covers the questions we hear most often. If you do not find what you need here, our support team is always available to help.

<AccordionGroup>

  <Accordion title="What is Exsited?">
    Exsited is an integration-first operations platform built for growing businesses. It connects your accounting software, eCommerce storefront, and internal workflows into a single, coordinated system — giving your team a unified view of orders, inventory, customers, suppliers, and approvals without the manual data entry that comes from juggling disconnected tools.
  </Accordion>

  <Accordion title="Which accounting platforms does Exsited support?">
    Exsited integrates natively with the most widely used accounting platforms in Australia and globally, including **Xero**, **MYOB**, and **QuickBooks Online**. Connections are bi-directional: orders, invoices, purchase orders, and payments sync automatically between Exsited and your accounting platform in real time.

    If you use a platform not listed here, contact [support@exsited.com](mailto:support@exsited.com) to ask about custom integration options.
  </Accordion>

  <Accordion title="Which eCommerce platforms does Exsited connect to?">
    Exsited supports integrations with leading eCommerce platforms including **Shopify**, **BigCommerce**, **Amazon**, **eBay**, and **Catch**. When connected, customer orders placed on your storefront flow directly into Exsited for processing, fulfilment, and accounting sync — eliminating the need to manually re-enter orders.
  </Accordion>

  <Accordion title="Can I use Exsited without an integration?">
    Yes. While Exsited is designed to be most powerful when connected to your other platforms, you can use it as a standalone operations tool — managing orders, purchase orders, contacts, inventory, and approvals entirely within Exsited. You can add integrations at any time as your business grows.
  </Accordion>

  <Accordion title="How do I add a new user?">
    Go to **Configuration → Users → Invite User**. Enter the user's name and email address, assign them a role (Admin, Manager, Staff, or Viewer), and select which modules they should access. Click **Send Invite** and they will receive an email to set up their account.

    For a detailed walkthrough, see the [User Roles and Permissions](/configuration/user-roles) guide.
  </Accordion>

  <Accordion title="What happens if a sync fails?">
    When a sync fails, Exsited logs the error and sends an email notification to Admin users. You can view the details of any sync failure in **Configuration → System Settings → Audit Logs**, or navigate to the integration's status page under **Integrations**.

    Common causes include expired authentication tokens, mismatched tax codes between platforms, and records with missing required fields. Most sync errors include a plain-language description of the issue and a suggested resolution step.

    For a step-by-step resolution guide, see [Troubleshooting Common Issues](/support/troubleshooting).
  </Accordion>

  <Accordion title="Does Exsited support multiple currencies?">
    Yes. You can enable multi-currency support under **Configuration → System Settings → Currency**. Set your base currency and configure additional currencies with manual or automatically synced exchange rates. If your connected accounting platform supports multi-currency natively (such as Xero), Exsited defers to that platform's exchange rate settings to keep everything consistent.
  </Accordion>

  <Accordion title="Is there an API I can use?">
    Yes, Exsited provides a REST API that allows you to read and write data programmatically. You can use the API to build custom integrations, automate workflows, or pull data into your own reporting tools. Authentication is handled via bearer tokens, which you can generate under **Configuration → API Keys**.

    Refer to the API documentation for endpoint references, authentication details, and code examples.
  </Accordion>

  <Accordion title="Where can I find the API documentation?">
    The full API reference is available in the **API** section of this documentation site. It covers all available endpoints, request and response formats, authentication, rate limits, and example requests in multiple languages.

    If you need a specific endpoint or have a custom integration use case, contact [support@exsited.com](mailto:support@exsited.com).
  </Accordion>

    You have several options for getting help with Exsited:

    - **Email:** [support@exsited.com](mailto:support@exsited.com) — our team responds to all enquiries during business hours.

    - **Documentation:** Browse this site for guides, tutorials, and reference material.

    For onboarding help or account changes (such as billing or subdomain updates), contact your dedicated Exsited account manager.
  </Accordion>
