An accounting code is a settings record that carries a general ledger account number and name and a code type such as `sales_revenue`. You can list, create, read, update and delete accounting codes. This area has 5 endpoints, and all seven SDKs call every one.

## At a glance

| Endpoint | Method | Path | What it does |
| --- | --- | --- | --- |
| [List accounting codes](/api-reference/accounting-codes/list-accounting-codes) | <span style={{fontFamily: "var(--font-mono, monospace)", fontSize: "0.72rem", fontWeight: 700, letterSpacing: "0.02em", color: "#0f7b6c"}}>GET</span> | `/settings/accounting_codes` | Returns a page of accounting codes under `data`, with paging details under `pagination`. |
| [Create an accounting code](/api-reference/accounting-codes/create-an-accounting-code) | <span style={{fontFamily: "var(--font-mono, monospace)", fontSize: "0.72rem", fontWeight: 700, letterSpacing: "0.02em", color: "#2563eb"}}>POST</span> | `/settings/accounting_codes` | Creates an accounting code and returns it under `accounting_code`. |
| [Retrieve an accounting code](/api-reference/accounting-codes/retrieve-an-accounting-code) | <span style={{fontFamily: "var(--font-mono, monospace)", fontSize: "0.72rem", fontWeight: 700, letterSpacing: "0.02em", color: "#0f7b6c"}}>GET</span> | `/settings/accounting_codes/{accounting_code_id}` | Returns one accounting code by its `id`, under `accounting_code`. |
| [Delete an accounting code](/api-reference/accounting-codes/delete-an-accounting-code) | <span style={{fontFamily: "var(--font-mono, monospace)", fontSize: "0.72rem", fontWeight: 700, letterSpacing: "0.02em", color: "#c2410c"}}>DELETE</span> | `/settings/accounting_codes/{accounting_code_id}` | Deletes an accounting code. The response has no body. |

## Before you call

Register your API credentials once when your app starts, as shown in
[Authentication](/authentication). Every SDK sample on these pages then gets its client in one line.
With cURL, send the access token in an `Authorization` header: `Authorization: Bearer $ACCESS_TOKEN`.

## Things to know

- **Requests and responses wrap the record in `accounting_code`.** A create sends `{"accounting_code": {...}}` and a read returns the record under the same key.
- **A create sets the code type with `account_code_type`.** The stored record reports the same value in `default_match_key`, such as `sales_revenue`.
- **Discount profiles need a discount accounting code.** A discount profile accepts only an accounting code whose `default_match_key` is `discount`.
- **Listings page by cursor.** Pass `limit` for the page size, then pass `pagination.next_cursor` back as `cursor` while `pagination.has_more` is true.
- **A delete returns `204` with no body.** Reading the accounting code afterwards returns `404`.
