Custom attributes are fields you define yourself, such as a text, number or dropdown value, and attach to records like accounts. This area has 5 endpoints to list, create, read, update and delete them, and all seven SDKs call every one.

## At a glance

| Endpoint | Method | Path | What it does |
| --- | --- | --- | --- |
| [List custom attributes](/api-reference/custom-attributes/list-custom-attributes) | <span style={{fontFamily: "var(--font-mono, monospace)", fontSize: "0.72rem", fontWeight: 700, letterSpacing: "0.02em", color: "#0f7b6c"}}>GET</span> | `…/custom_attributes` | Returns one page of the custom attributes defined on your Exsited account. |
| [Create a custom attribute](/api-reference/custom-attributes/create-a-custom-attribute) | <span style={{fontFamily: "var(--font-mono, monospace)", fontSize: "0.72rem", fontWeight: 700, letterSpacing: "0.02em", color: "#2563eb"}}>POST</span> | `…/custom_attributes` | Creates a custom attribute and returns it, under `custom_attribute`. |
| [Delete a custom attribute](/api-reference/custom-attributes/delete-a-custom-attribute) | <span style={{fontFamily: "var(--font-mono, monospace)", fontSize: "0.72rem", fontWeight: 700, letterSpacing: "0.02em", color: "#c2410c"}}>DELETE</span> | `…/custom_attributes/{custom_attribute_id}` | Deletes a custom attribute and returns no body. |
| [Retrieve a custom attribute](/api-reference/custom-attributes/retrieve-a-custom-attribute) | <span style={{fontFamily: "var(--font-mono, monospace)", fontSize: "0.72rem", fontWeight: 700, letterSpacing: "0.02em", color: "#0f7b6c"}}>GET</span> | `…/custom_attributes/{custom_attribute_id}` | Returns one custom attribute, under `custom_attribute`. |
| [Update a custom attribute](/api-reference/custom-attributes/update-a-custom-attribute) | <span style={{fontFamily: "var(--font-mono, monospace)", fontSize: "0.72rem", fontWeight: 700, letterSpacing: "0.02em", color: "#7a5af8"}}>PATCH</span> | `…/custom_attributes/{custom_attribute_id}` | Changes a custom attribute's fields and returns the updated attribute. |

## Before you call

Register your API credentials once when your app starts, as shown in
[Authentication](/authentication). Every SDK sample on these pages then gets its client in one line.
With cURL, send the access token in an `Authorization` header: `Authorization: Bearer $ACCESS_TOKEN`.

## Things to know

- **Every write sends its fields under `custom_attribute`.** The create and update bodies wrap the fields in `custom_attribute`, and one attribute comes back under the same key.
- **A create needs `name`, `display_name` and `type`.** Those are the fields the create example sends; `type` takes values such as `STRING`, `NUMBER` and `DROPDOWN`.
- **Dropdown options go in as strings and come back as objects.** Send `options` as a list of strings; the response lists each option as an object with `name` and `display_order`.
- **A create returns 201 with two extra fields.** The created attribute also carries `uuid` and `activity_logs`.
- **The listing pages by cursor.** Pass `limit`, then the `next_cursor` from `pagination` as `cursor` while `has_more` is true.
- **A delete returns 204 with no body.** Reading the attribute afterwards returns 404.
