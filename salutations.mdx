Salutations are the settings records for forms of address. You can list, create, read, update and delete them. This area has 5 endpoints, and all seven SDKs call every one.

## At a glance

| Endpoint | Method | Path | What it does |
| --- | --- | --- | --- |
| [List salutations](/api-reference/salutations/list-salutations) | <span style={{fontFamily: "var(--font-mono, monospace)", fontSize: "0.72rem", fontWeight: 700, letterSpacing: "0.02em", color: "#0f7b6c"}}>GET</span> | `/settings/salutations` | Returns a page of salutations under `data`, with paging details under `pagination`. |
| [Create a salutation](/api-reference/salutations/create-a-salutation) | <span style={{fontFamily: "var(--font-mono, monospace)", fontSize: "0.72rem", fontWeight: 700, letterSpacing: "0.02em", color: "#2563eb"}}>POST</span> | `/settings/salutations` | Creates a salutation and returns it under `salutation`. |
| [Retrieve a salutation](/api-reference/salutations/retrieve-a-salutation) | <span style={{fontFamily: "var(--font-mono, monospace)", fontSize: "0.72rem", fontWeight: 700, letterSpacing: "0.02em", color: "#0f7b6c"}}>GET</span> | `/settings/salutations/{salutation_id}` | Returns one salutation by its `id`, under `salutation`. |
| [Delete a salutation](/api-reference/salutations/delete-a-salutation) | <span style={{fontFamily: "var(--font-mono, monospace)", fontSize: "0.72rem", fontWeight: 700, letterSpacing: "0.02em", color: "#c2410c"}}>DELETE</span> | `/settings/salutations/{salutation_id}` | Deletes a salutation. The response has no body. |
| [Update a salutation](/api-reference/salutations/update-a-salutation) | <span style={{fontFamily: "var(--font-mono, monospace)", fontSize: "0.72rem", fontWeight: 700, letterSpacing: "0.02em", color: "#7a5af8"}}>PATCH</span> | `/settings/salutations/{salutation_id}` | Changes the fields you send on a salutation and returns it under `salutation`. |

## Before you call

Register your API credentials once when your app starts, as shown in
[Authentication](/authentication). Every SDK sample on these pages then gets its client in one line.
With cURL, send the access token in an `Authorization` header: `Authorization: Bearer $ACCESS_TOKEN`.

## Things to know

- **Requests and responses wrap the record in `salutation`.** A create sends `{"salutation": {...}}`.
- **A create needs only a `name`.** The new salutation's `display_name` takes the same value.
- **Listings page by cursor.** Pass `limit` for the page size, then pass `pagination.next_cursor` back as `cursor` while `pagination.has_more` is true.
- **A delete returns `204` with no body.** Reading the salutation afterwards returns `404`.
