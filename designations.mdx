Designations are the job titles configured in your Exsited settings. You can list, create, retrieve, update and delete them. This area has 5 endpoints, each available in all seven SDKs.

<Warning>
  **Creating a designation currently fails.** `POST /settings/designations` returns `404` for the designation it has just saved and leaves no record, so the create, update and delete calls have not been confirmed to work. Deleting a designation cannot be undone.
</Warning>

## At a glance

| Endpoint | Method | Path | What it does |
| --- | --- | --- | --- |
| [List designations](/api-reference/designations/list-designations) | <span style={{fontFamily: "var(--font-mono, monospace)", fontSize: "0.72rem", fontWeight: 700, letterSpacing: "0.02em", color: "#0f7b6c"}}>GET</span> | `/settings/designations` | Lists the designations (job titles) set up in Exsited, one page at a time. |
| [Create a designation](/api-reference/designations/create-a-designation) | <span style={{fontFamily: "var(--font-mono, monospace)", fontSize: "0.72rem", fontWeight: 700, letterSpacing: "0.02em", color: "#2563eb"}}>POST</span> | `/settings/designations` | Creates a designation and returns it under `designation`. |
| [Retrieve a designation](/api-reference/designations/retrieve-a-designation) | <span style={{fontFamily: "var(--font-mono, monospace)", fontSize: "0.72rem", fontWeight: 700, letterSpacing: "0.02em", color: "#0f7b6c"}}>GET</span> | `/settings/designations/{designation_id}` | Retrieves one designation by its `des_` id. |
| [Delete a designation](/api-reference/designations/delete-a-designation) | <span style={{fontFamily: "var(--font-mono, monospace)", fontSize: "0.72rem", fontWeight: 700, letterSpacing: "0.02em", color: "#c2410c"}}>DELETE</span> | `/settings/designations/{designation_id}` | Deletes a designation; the response has no body. |
| [Update a designation](/api-reference/designations/update-a-designation) | <span style={{fontFamily: "var(--font-mono, monospace)", fontSize: "0.72rem", fontWeight: 700, letterSpacing: "0.02em", color: "#7a5af8"}}>PATCH</span> | `/settings/designations/{designation_id}` | Changes a designation's name, display name or description. |

## Before you call

Register your API credentials once when your app starts, as shown in
[Authentication](/authentication). Every SDK sample on these pages then gets its client in one line.
With cURL, send the access token in an `Authorization` header: `Authorization: Bearer $ACCESS_TOKEN`.

## Things to know

- **Request bodies go under `designation`.** Both the create and the update wrap their fields in a `designation` object, and the response returns the record under the same key.
- **`name` is required to create a designation.**
- **Designation ids start with `des_`.** Pass that `id` as `designation_id`.
- **The list pages by cursor.** Records are under `data`; pass `pagination.next_cursor` as `cursor` while `pagination.has_more` is `true`.
