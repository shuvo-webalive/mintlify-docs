The Items API gives you full control over your product and service catalogue in Exsited. Items are the building blocks of orders and invoices — every line item on a sales order or invoice maps to a record in your catalogue. Use this API to keep your Exsited catalogue in sync with an external PIM, ERP, or e-commerce platform, or to manage stock levels programmatically as inventory changes.

## Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/api/v3/items` | List all items in the catalogue. |
| `POST` | `/api/v3/items` | Create a new item. |
| `GET` | `/api/v3/items/{id}` | Retrieve a single item by ID. |
| `PATCH` | `/api/v3/items` | Partially update one or more items. |
| `DELETE` | `/api/v3/items` | Delete one or more items. |

## List Items

Retrieve a paginated list of all items in your catalogue.

```bash
curl https://example.exsited.com/api/v3/items?limit=20&offset=0&order_by=created_on&direction=desc \
  -H "Authorization: Bearer <token>"
```

## Retrieve an Item

Fetch full details for a single item using its unique ID.

```bash
curl https://example.exsited.com/api/v3/items/itm_01HXYZ456 \
  -H "Authorization: Bearer <token>"
```

## Create an Item

Send a `POST` request with the item details. Provide at least a `name` and `price` to create a valid item.

```bash
curl -X POST https://example.exsited.com/api/v3/items \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "sku": "WIDGET-BLU-L",
    "name": "Blue Widget (Large)",
    "description": "A large blue widget suitable for industrial applications.",
    "price": 49.99,
    "stock_quantity": 250,
    "barcode": "9780000000002",
    "status": "active"
  }'
```

## Update an Item

Use `PATCH` to update specific fields on one or more items without replacing the full record.

```bash
curl -X PATCH https://example.exsited.com/api/v3/items \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "id": "itm_01HXYZ456",
    "price": 54.99,
    "stock_quantity": 300
  }'
```

## Delete an Item

```bash
curl -X DELETE https://example.exsited.com/api/v3/items \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{
    "ids": ["itm_01HXYZ456"]
  }'
```

<Warning>
  Deleting an item removes it from the catalogue permanently. Items referenced on existing orders or invoices retain their data, but the item will no longer be selectable for new records.
</Warning>

## Request Fields

<ParamField body="sku" type="string">
  Your internal stock-keeping unit code. Must be unique across your catalogue.
</ParamField>

<ParamField body="name" type="string" required>
  The display name of the product or service.
</ParamField>

<ParamField body="description" type="string">
  A longer description of the item, displayed on invoices and in the customer portal.
</ParamField>

<ParamField body="price" type="number" required>
  The unit price of the item, expressed as a decimal (e.g. `49.99`).
</ParamField>

<ParamField body="stock_quantity" type="integer">
  Current quantity in stock. Omit for service items that do not have physical inventory.
</ParamField>

<ParamField body="barcode" type="string">
  A barcode or EAN associated with the item, used for scanning and warehouse workflows.
</ParamField>

<ParamField body="status" type="string">
  Item availability status. Accepted values: `active`, `inactive`. Defaults to `active`.
</ParamField>

## Response Fields

<ResponseField name="id" type="string">
  The unique identifier assigned to the item by Exsited.
</ResponseField>

<ResponseField name="sku" type="string">
  Your internal stock-keeping unit code.
</ResponseField>

<ResponseField name="name" type="string">
  The display name of the item.
</ResponseField>

<ResponseField name="description" type="string">
  The item description.
</ResponseField>

<ResponseField name="price" type="number">
  The unit price of the item.
</ResponseField>

<ResponseField name="stock_quantity" type="integer">
  Current stock quantity on hand.
</ResponseField>

<ResponseField name="barcode" type="string">
  Barcode or EAN for the item.
</ResponseField>

<ResponseField name="status" type="string">
  Current status of the item: `active` or `inactive`.
</ResponseField>

<ResponseField name="created_on" type="string">
  ISO 8601 timestamp of when the item was created.
</ResponseField>
