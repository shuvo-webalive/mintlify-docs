The Exsited SDKs give you a idiomatic, language-native way to interact with the Exsited API. Instead of hand-crafting HTTP requests and managing tokens yourself, you get a clean client library that handles authentication, retries, and error reporting out of the box. SDKs are currently available for Python and PHP, with the same resource coverage across both languages.

## Feature Highlights

Every Exsited SDK ships with the same core capabilities so you get a consistent experience regardless of the language you work in.

| Feature | Details |
|---|---|
| **OAuth 2.0 built-in** | Client Credentials flow handled for you — just supply your `client_id` and `client_secret` |
| **Automatic token refresh** | The SDK detects expired tokens and refreshes them transparently, so your requests never fail mid-session |
| **Full CRUD coverage** | Create, read, update, and delete operations for every supported resource |
| **Automatic retries** | Transient network errors and rate-limit responses are retried automatically with back-off |
| **Detailed error messages** | Structured error responses tell you exactly what went wrong and how to fix it |
| **Environment flexibility** | Point the SDK at your development, staging, or production Exsited instance by changing a single URL |

## Supported Modules

The SDKs cover all major Exsited resource types. Every module below is accessible through the same SDK client instance.

| Module | Description |
|---|---|
| **Accounts** | Create and manage customer and supplier accounts |
| **Items** | Define products, services, and inventory records |
| **Orders** | Create and track sales orders through fulfilment |
| **Invoices** | Generate, send, and reconcile invoices |
| **Payments** | Record and manage payment transactions |
| **Purchase Orders** | Raise and track supplier purchase orders |
| **Credit Notes** | Issue and apply credit notes against invoices |
| **Refunds** | Process and track refund transactions |
| **Gift Certificates** | Create and redeem gift certificate records |
| **RMA** | Manage return merchandise authorisation requests |
| **Portals** | Configure and manage customer self-service portals |
| **Reports** | Pull financial and operational reports programmatically |
| **Settings** | Read and update account-level platform settings |
| **Integration** | Manage third-party integration configurations |
| **Communications** | Send and retrieve messages, emails, and notifications |
| **Custom Objects** | Define and interact with custom data structures |
| **Labour** | Track labour entries and time-based billing |
| **Workflows** | Trigger and monitor automated workflow executions |

<Note>
  To obtain your `client_id`, `client_secret`, and `redirect_uri`, contact your Exsited account manager or log in to your Exsited dashboard and navigate to **Settings → API Credentials**.
</Note>
