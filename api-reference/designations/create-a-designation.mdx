---
title: "Create a designation"
description: "Creates a designation and returns it under `designation`."
openapi: "POST /settings/designations"
---

Send the new designation under `designation`. `name` is required. The new designation comes back under `designation`, with its `des_` id.

<Warning>
  **This call currently returns `404`.** The create reports the designation it has just saved as not found and leaves no designation, so the `201` response below has not been confirmed.
</Warning>

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token). To send a raw JSON body instead of filling in fields, copy the cURL sample and edit its `-d` payload.</Note>
