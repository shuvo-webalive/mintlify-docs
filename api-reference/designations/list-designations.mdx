---
title: "List designations"
description: "Lists the designations (job titles) set up in Exsited, one page at a time."
openapi: "GET /settings/designations"
---

Returns one page of designations under `data`, with `pagination` for the next page. Each designation carries its `id`, `name`, `display_name`, `description` and `status`. Any other field of the record filters the listing as `filter_<field>` or `filter_<field>_<operator>`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
