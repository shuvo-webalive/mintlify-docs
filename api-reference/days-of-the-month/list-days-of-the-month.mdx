---
title: "List days of the month"
description: "Returns a page of the days of the month a date can be aligned to, under `data`."
openapi: "GET /settings/day_of_month"
---

Lists the days of the month a date can be aligned to. Each record carries its `day` number. Pass `limit` to set the page size, and while `pagination.has_more` is true pass `pagination.next_cursor` back as `cursor` to read the next page. Other fields filter as `filter_<field>` or `filter_<field>_<operator>`, and `sort` orders the results.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
