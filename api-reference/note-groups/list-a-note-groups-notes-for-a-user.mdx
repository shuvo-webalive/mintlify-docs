---
title: "List a note group's notes for a user"
description: "Lists a note group's notes as one of its users sees them."
openapi: "GET /note_groups/{note_group_id}/notes/user/{note_user}"
---

Name the user by the note user's uuid, by the uuid of the entity it stands for, or by a manual user's email address. Returns a page of notes under `data`, with cursor `pagination`. A user the group does not hold returns `404`. Other fields filter as `filter_<field>` for equality or `filter_<field>_<operator>`, such as `filter_created_on_gte`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
