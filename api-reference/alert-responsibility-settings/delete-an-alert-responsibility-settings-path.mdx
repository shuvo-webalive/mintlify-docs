---
title: "Delete an alert responsibility (settings path)"
description: "Deletes an alert responsibility from the settings area. Nothing comes back."
openapi: "DELETE /settings/alert_responsibilities/{alert_responsibility_id}"
---

Returns `204` with no body. Your API client needs the `MANAGE_ALERT_RESPONSIBILITY` permission.

<Warning>
  **This call has not been confirmed.** The same record can be handled under `/alert_responsibility`.
</Warning>

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
