---
title: "List alert responsibilities"
description: "Lists the alert responsibilities on your instance, one page at a time."
openapi: "GET /alert_responsibility"
---

Returns a page of alert responsibilities under `data`, with cursor `pagination`. The path is singular. Other fields filter as `filter_<field>` for equality or `filter_<field>_<operator>`, such as `filter_created_on_gte`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
