---
title: "Create an express purchase order"
description: "Creates a purchase order for a supplier in one call and returns it under `purchase_express`."
openapi: "POST /purchase_express"
---

Creates a purchase order for a supplier in one call, with the body under `account.purchase_order`. The API also accepts a nested purchase invoice and payment, but their fields are not documented yet; without them, only the purchase order is created and nothing is billed or paid. The new purchase order comes back under `purchase_express`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token). To send a raw JSON body instead of filling in fields, copy the cURL sample and edit its `-d` payload.</Note>
