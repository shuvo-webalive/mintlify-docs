---
title: "List an invoice's credit note applications"
description: "Returns one page of the credit note applications made to one invoice."
openapi: "GET /invoices/{invoice_id}/credit_note_applications"
---

Lists the credit note applications made against the invoice, one page at a time, under `data`. To filter, add `filter_<field>=<value>`, or `filter_<field>_<operator>=<value>` with an operator such as `gte` or `contains`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
