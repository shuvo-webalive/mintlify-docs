---
title: "List credit note applications"
description: "Returns one page of credit note applications across all invoices."
openapi: "GET /credit_note_applications"
---

Lists every credit note application, one page at a time, under `data`. Each record names its `credit_note`, the `payment` it made and the `amount` applied. Other fields filter as `filter_<field>`, or `filter_<field>_<operator>` with an operator such as `gte` or `contains`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
