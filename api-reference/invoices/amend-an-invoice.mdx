---
title: "Amend an invoice"
description: "Adds, changes or removes invoice lines and returns the invoice."
openapi: "POST /invoices/{invoice_id}/amend"
---

Amends the invoice's lines. Each entry of `invoice.lines` names an `op`: `add` with the new line under `value`, `change` with the line's `id` as `charge_item_uuid` and the new price or quantity, or `remove` with the line's `id` as `charge_item_uuid`. Each amendment raises the invoice's `version` by one. The body is optional.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token). To send a raw JSON body instead of filling in fields, copy the cURL sample and edit its `-d` payload.</Note>
