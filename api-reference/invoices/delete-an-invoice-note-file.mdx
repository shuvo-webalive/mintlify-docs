---
title: "Delete an invoice note file"
description: "Deletes one file from a note on an invoice."
openapi: "DELETE /invoices/{invoice_id}/notes/{note_id}/files/{file_id}"
---

Deletes the attachment by its `uuid`. A delete returns `204` with no body.

<Warning>
  **This call currently returns `404`.** The message is `attachment not found`, even for a file the note's files listing shows.
</Warning>

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
