---
title: "Retrieve an invoice's custom object"
description: "Returns one custom object with this invoice's instances of it."
openapi: "GET /invoices/{invoice_id}/custom_objects/{custom_object_id}"
---

Fetches a custom object defined for invoices, together with the instances of it that belong to this invoice.

<Warning>
  **This call has not been confirmed to work.** The response body is not documented yet.
</Warning>

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
