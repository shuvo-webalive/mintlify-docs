---
title: "Retrieve an invoice's return merchandise authorisation"
description: "Returns one return merchandise authorisation raised against an invoice."
openapi: "GET /invoices/{invoice_id}/return_merchandise_authorisations/{rma_id}"
---

Fetches a single return merchandise authorisation of the invoice, with its lines. One that belongs to a different invoice returns `404`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
