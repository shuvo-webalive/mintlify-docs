---
title: "List an invoice's return merchandise authorisations"
description: "Returns one page of the return merchandise authorisations raised against an invoice."
openapi: "GET /invoices/{invoice_id}/return_merchandise_authorisations"
---

Lists the invoice's return merchandise authorisations, one page at a time, under `data`. The path uses the British spelling `authorisations`; the spelling with a `z` returns `404`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
