---
title: "Retrieve a credit note application through an invoice"
description: "Returns one credit note application by its `id`."
openapi: "GET /invoices/{invoice_id}/credit_note_applications/{credit_note_application_id}"
---

Fetches a credit note application under `credit_note_application`. The server does not check that the application belongs to the invoice: any application is returned under any invoice that exists.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
