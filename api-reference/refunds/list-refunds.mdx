---
title: "List refunds"
description: "Returns one page of refunds."
openapi: "GET /refunds"
---

Lists every refund, one page at a time, under `data`. Each record carries its `amount` as a string, the `payment_method`, the `reconcile_status`, and the account and credit note it belongs to. To filter, add `filter_<field>=<value>`, or `filter_<field>_<operator>=<value>` with an operator such as `gte` or `contains`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
