---
title: "Delete a refund note file"
description: "Deletes one file from a note on a refund."
openapi: "DELETE /refunds/{refund_id}/notes/{note_id}/files/{file_id}"
---

Deletes the attachment by its `uuid`. The server checks the `CREATE_REFUND_NOTE` permission.

<Warning>
  **This call has not been confirmed to work.** No successful delete has been confirmed. Deleting a payment note takes the note's `id` as a dashed uuid rather than its `note_` id, and this call may do the same.
</Warning>

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
