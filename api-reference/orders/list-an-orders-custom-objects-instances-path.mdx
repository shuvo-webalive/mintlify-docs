---
title: "List an order's custom objects (instances path)"
description: "Lists an order's custom objects through the `custom_objects_instances` path, one page at a time."
openapi: "GET /orders/{order_id}/custom_objects_instances"
---

This path returns the same listing as `GET /orders/{order_id}/custom_objects`. The records are under `data`, and `pagination` holds the cursor for the next page.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
