---
title: "Retrieve an order's custom object"
description: "Returns one custom object with the order's instances of it, under `custom_object`."
openapi: "GET /orders/{order_id}/custom_objects/{custom_object_id}"
---

Pass the order's `id` and the custom object's `id`. The order's instances of the object are under `instances`; an order with none returns an empty list.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
