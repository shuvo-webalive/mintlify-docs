---
title: "Retrieve an order's custom object instance by the instances path"
description: "Returns one instance of a custom object on an order, through the `custom_objects_instances` path."
openapi: "GET /orders/{order_id}/custom_objects_instances/{custom_object_id}/instances/{instance_id}"
---

This path returns the same body as `GET /orders/{order_id}/custom_objects/{custom_object_id}/instances/{instance_id}`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
