---
title: "List rental asset profiles"
description: "Lists rental asset profiles, one page at a time."
openapi: "GET /rental_asset_profiles"
---

Returns one page of profiles under `data`. Each profile carries its currency, sessions with prices and hours, and the rental assets that use it. Other fields filter as `filter_<field>` for equality and `filter_<field>_<operator>` otherwise.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
