---
title: "Update rental asset availability"
description: "Sets the weekly or custom hours of one or more rental assets."
openapi: "PATCH /rental_asset_availability"
---

Send a `rental_assets` list. Each entry names an asset by `id` and carries `rental_asset_availability` for weekly hours or `rental_asset_custom_availability` for custom hours. An entry with only the `id` is accepted. Set the asset's `use_custom_availability` to `true` (Update a rental asset) before sending custom hours; whether it is required is not documented.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token). To send a raw JSON body instead of filling in fields, copy the cURL sample and edit its `-d` payload.</Note>
