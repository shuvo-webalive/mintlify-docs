---
title: "List rental asset availability"
description: "Lists each rental asset with its schedule, one page at a time."
openapi: "GET /rental_asset_availability"
---

Returns one page under `data`, one row per rental asset, with its profile, `session_list`, `schedule_list` and the available and unavailable times. Other fields filter as `filter_<field>` for equality and `filter_<field>_<operator>` otherwise.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
