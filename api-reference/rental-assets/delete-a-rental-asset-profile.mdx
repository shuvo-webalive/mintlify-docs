---
title: "Delete a rental asset profile"
description: "Deletes a rental asset profile."
openapi: "DELETE /rental_asset_profiles/{rental_asset_profile_id}"
---

Deletes the profile; a later read returns `404`. It is not documented whether a profile that rental assets still use can be deleted.

<Warning>
  **The `200` status of this call has not been confirmed.** Read the profile afterwards; a deleted profile returns `404`.
</Warning>

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
