---
title: "List component objects"
description: "Returns one page of a component's objects."
openapi: "GET /components/{component_uuid}/objects"
---

Lists the objects of the component with this `cmp_` id, with each object's owner in `parents`, its attributes, its workflow state and the accounts, items, orders and quotes linked to it. Records are under `data` and paging details under `pagination`. Fields filter as `filter_<field>`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
