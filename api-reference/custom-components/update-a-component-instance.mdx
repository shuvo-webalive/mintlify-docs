---
title: "Update a component instance"
description: "Changes a component instance and returns it under the component's name."
openapi: "PATCH /component/{component_uuid}/{component_object_id}"
---

Updates the instance with this `id` in the component with this dashed `uuid`. The body has one key, the component's `name`, holding the fields to change, such as `attributes`. The updated instance comes back under the same key with a new `version`. The shape of each `attributes` entry is not documented yet; the example sends an empty list.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token). To send a raw JSON body instead of filling in fields, copy the cURL sample and edit its `-d` payload.</Note>
