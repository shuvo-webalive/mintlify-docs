---
title: "List the files of a component object's note"
description: "Returns the files attached to a note on a component object."
openapi: "GET /components/{component_uuid}/objects/{component_object_id}/notes/{note_id}/files"
---

Lists the files attached to the note, each with its `uuid`, file name, content type and size. Files are under `data`; `pagination` carries `has_more` only.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
