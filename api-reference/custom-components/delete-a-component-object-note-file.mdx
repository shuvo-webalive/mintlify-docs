---
title: "Delete a component object note file"
description: "Deletes one file from a note and returns no body."
openapi: "DELETE /components/{component_uuid}/objects/{component_object_id}/notes/{note_id}/files/{file_id}"
---

Removes the attachment with this `uuid` from the note. A successful call returns 204 with an empty body, and the note's files listing no longer shows it.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
