---
title: "Update a component object"
description: "Changes a component object and returns it, under `custom_component_object`."
openapi: "PATCH /components/{component_uuid}/objects/{component_object_id}"
---

Send the fields to change under `custom_component_object`, such as `attributes`. If you send `version_id`, it must match the object's current version. `code`, `parents` and `custom_form` cannot be changed and are refused. Each update raises the object's `version` by one.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token). To send a raw JSON body instead of filling in fields, copy the cURL sample and edit its `-d` payload.</Note>
