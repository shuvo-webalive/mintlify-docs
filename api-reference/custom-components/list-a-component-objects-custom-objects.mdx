---
title: "List a component object's custom objects"
description: "Returns one page of the custom objects linked to a component object."
openapi: "GET /components/{component_uuid}/objects/{component_object_id}/custom_objects"
---

Lists the custom objects linked to the object. Entries are under `data` and paging details under `pagination`. Fields filter as `filter_<field>`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
