---
title: "Create a component object note"
description: "Adds a note, with optional files, to a component object and returns it, under `note`."
openapi: "POST /components/{component_uuid}/objects/{component_object_id}/notes"
---

Send a multipart form with the note's text in the `note` field and any files beside it. The new note comes back with its `id`, its content and one entry in `attachments` for each file.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
