---
title: "Delete a custom object instance on a component object"
description: "Deletes a custom object instance on a component object and returns no body."
openapi: "DELETE /components/{component_uuid}/objects/{component_object_id}/custom_objects/{custom_object_id}/instances/{instance_id}"
---

Removes the instance with this `coi_` id from the custom object with this `co_` id. A successful call returns 204 with an empty body.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
