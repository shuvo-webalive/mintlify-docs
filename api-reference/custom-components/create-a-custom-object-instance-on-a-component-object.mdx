---
title: "Create a custom object instance on a component object"
description: "Creates an instance of a custom object on a component object."
openapi: "POST /components/{component_uuid}/objects/{component_object_id}/custom_objects/{custom_object_id}"
---

Creates a new instance of the custom object with this `co_` id. The path ends at the custom object, with no `instances` segment. Send the instance's `attributes` list under `custom_object_instances`, a plural key over one instance. The shape of each `attributes` entry is not documented yet; the example sends an empty list.

<Warning>
  **This call has not been confirmed.** Read the record afterwards to check the result.
</Warning>
