---
title: "Update a component object note"
description: "Changes a note's text, with optional files, and returns the note, under `note`."
openapi: "PATCH /components/{component_uuid}/objects/{component_object_id}/notes/{note_id}"
---

Send a multipart form, as for the create, with the new text in the `note` field and any files beside it. The updated note comes back with its `version` raised by one.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
