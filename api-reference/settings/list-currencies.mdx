---
title: "List currencies"
description: "Returns a page of currencies under `data`, with paging details under `pagination`."
openapi: "GET /settings/currencies"
---

Lists the currencies on the instance. Each currency has a `code`, such as `AUD`, a `symbol` and a `conversion_rate`. Pass `limit` to set the page size, and while `pagination.has_more` is true pass `pagination.next_cursor` back as `cursor` to read the next page. Other fields filter as `filter_<field>` or `filter_<field>_<operator>`, and `sort` orders the results.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
