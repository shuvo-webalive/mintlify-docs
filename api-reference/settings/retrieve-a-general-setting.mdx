---
title: "Retrieve a general setting"
description: "Returns one general setting row by its `gs_` `id` within a group."
openapi: "GET /settings/general_settings/{group}/{general_setting_id}"
---

Reads one general setting row by its `gs_` `id`. No response carries a `gs_` id, so there is no known way to obtain one. An `id` the group does not hold returns `404`, and an unknown group returns `400`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
