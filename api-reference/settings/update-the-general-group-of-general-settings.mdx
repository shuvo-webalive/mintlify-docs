---
title: "Update the general group of general settings"
description: "Changes settings in the `general` group. It also resets eight other instance settings that no call can set back."
openapi: "PATCH /settings/general_settings/general"
---

Send the settings to change under `general_settings.general`. Saving this group also sets `accountingPeriod`, `fiscalYear`, `autoSaveBudget`, `customComponentActivity`, `enableRequireAction`, `strictBankAccountMatching`, `enableGrandOdata` and `addressRestrictedMode` to null, and no API call writes them back. Do not send this call unless you can reset those settings in the Exsited web app.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token). To send a raw JSON body instead of filling in fields, copy the cURL sample and edit its `-d` payload.</Note>
