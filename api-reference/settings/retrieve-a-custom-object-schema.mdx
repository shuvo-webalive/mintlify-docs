---
title: "Retrieve a custom object schema"
description: "Returns one custom object schema by its `id`, under `custom_object`."
openapi: "GET /custom_objects/{custom_object_id}"
---

Reads the custom object schema with this `id`. The `id` is the one a listing or a create returns. A definition created through `/settings/custom_objects` can be read here with its `id` as well.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
