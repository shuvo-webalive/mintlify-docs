---
title: "Create an item fulfillment note"
description: "Adds a note to a fulfillment, with optional files, and returns the note's id."
openapi: "POST /item_fulfillments/{fulfillment_id}/notes"
---

Send a multipart form with the text in the `note` field and any files as extra parts. The note is stored on the fulfillment's sale invoice, and the response gives its `id` under `note`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
