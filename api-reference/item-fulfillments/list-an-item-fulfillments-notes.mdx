---
title: "List an item fulfillment's notes"
description: "Returns a page of the notes on a fulfillment's sale invoice."
openapi: "GET /item_fulfillments/{fulfillment_id}/notes"
---

Returns notes under `data`, each with its `content`, `attachments` and `watchers`. These are the notes of the fulfillment's sale invoice, which is where the create note endpoint puts them.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
