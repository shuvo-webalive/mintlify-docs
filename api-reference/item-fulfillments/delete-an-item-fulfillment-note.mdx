---
title: "Delete an item fulfillment note"
description: "Deletes a note held on the fulfillment itself. A successful call returns `204` with no body."
openapi: "DELETE /item_fulfillments/{fulfillment_id}/notes/{note_id}"
---

Pass the fulfillment's `ifm_` id and the note's `note_` id. The delete looks for the note on the fulfillment, not on its sale invoice, where the create note endpoint stores notes.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
