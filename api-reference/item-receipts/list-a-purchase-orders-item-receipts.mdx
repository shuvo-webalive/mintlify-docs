---
title: "List a purchase order's item receipts"
description: "Returns the item receipts of one purchase order."
openapi: "GET /purchase_orders/{purchase_order_id}/item_receipts"
---

Returns the item receipts of one purchase order. The response is expected under `purchase_order`, with the receipts in `item_receipts` and a `pagination` block; this shape has not been confirmed.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
