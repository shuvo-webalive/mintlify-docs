---
title: "Delete an item receipt"
description: "Deletes an item receipt. A successful call returns `204` with no body."
openapi: "DELETE /item_receipts/{item_receipt_id}"
---

Deletes the receipt with that `ir_` id; a later read of it returns `404`. A completed receipt cannot be deleted.

<Warning>
  **This call has not been confirmed to work.** Creating an item receipt currently fails; see [Create an item receipt](/api-reference/item-receipts/create-an-item-receipt).
</Warning>

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
