---
title: "Create a custom event"
description: "Creates a custom event built on a system event."
openapi: "POST /settings/custom_events"
---

`name` and `base_event` are required; `base_event` is an `se_` id. Creating the event also adds a message for it to every communication profile. No endpoint lists `se_` ids: the system events listing shows `evt_` ids, which this field does not accept.

<Warning>
  **This call has not been confirmed.** No endpoint returns the `se_` id that `base_event` needs.
</Warning>

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token). To send a raw JSON body instead of filling in fields, copy the cURL sample and edit its `-d` payload.</Note>
