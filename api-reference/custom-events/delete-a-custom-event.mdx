---
title: "Delete a custom event"
description: "Deletes a custom event that no workflow uses. Nothing comes back."
openapi: "DELETE /settings/custom_events/{custom_event_id}"
---

Returns `204` with no body. A custom event a workflow uses cannot be deleted. The messages its create added to the communication profiles stay behind.

<Warning>
  **This call has not been confirmed.** It needs a custom event made by the create.
</Warning>

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
