---
title: "List system events"
description: "Lists the base system events, one page at a time."
openapi: "GET /settings/system_events"
---

Returns a page of system events under `data`, with cursor `pagination`. System events are reference data and cannot be changed. Other fields filter as `filter_<field>` for equality or `filter_<field>_<operator>`, such as `filter_created_on_gte`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
