---
title: "Update an additional code"
description: "Changes the fields or the status of an additional code."
openapi: "PATCH /settings/additional_codes/{additional_code_id}"
---

Send the fields to change under `additional_code`. You can change its fields or its `status`. This call currently returns `500`; read the additional code again to see whether the change is stored.

<Warning>
  **This call currently returns `500`.** Read the additional code again to see whether the change is stored.
</Warning>

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token). To send a raw JSON body instead of filling in fields, copy the cURL sample and edit its `-d` payload.</Note>
