---
title: "Set a custom feature's form layout and attributes"
description: "Sets the form layout of a custom feature and the attributes in each column, and returns the feature."
openapi: "POST /custom_feature/{custom_feature_id}"
---

Customizes the form of an existing feature. Send `configuration` with `settings.form_layout`, such as `TWO_COLS`, and the entries of `column_1` and `column_2`: each entry is an `ATTRIBUTE`, named by a custom attribute's `name`, or a `LABEL`. The feature comes back under `custom_feature`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token). To send a raw JSON body instead of filling in fields, copy the cURL sample and edit its `-d` payload.</Note>
