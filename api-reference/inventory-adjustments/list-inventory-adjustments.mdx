---
title: "List inventory adjustments"
description: "Returns a page of inventory adjustments across all items."
openapi: "GET /inventory_adjustments"
---

Returns adjustments under `data`, each naming the item, the warehouse, the `adjustment_amount` and the quantities after the change. Set the page size with `limit` and fetch the next page with `cursor`. Other fields filter as `filter_<field>`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
