---
title: "List departments"
description: "Lists the departments set up in Exsited, one page at a time."
openapi: "GET /settings/departments"
---

Returns one page of departments under `data`, with `pagination` for the next page. Each department carries its `code`, `name`, `display_name`, `description`, `status` and the `division` it belongs to. Some departments in the list have a null `id`; those cannot be retrieved on their own. Any other field of the record filters the listing as `filter_<field>` or `filter_<field>_<operator>`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
