---
title: "Delete a custom form"
description: "Deletes a custom form that is not system generated and returns no body."
openapi: "DELETE /settings/custom_forms/{custom_form_id}"
---

Removes the custom form with this `cf_` id. Only a form that is not system generated can be deleted. A successful call returns `204` with an empty body, and reading the form afterwards returns `404`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
