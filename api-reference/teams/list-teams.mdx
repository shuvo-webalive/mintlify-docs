---
title: "List teams"
description: "Lists the teams set up in Exsited, one page at a time."
openapi: "GET /settings/teams"
---

Returns one page of teams under `data`, with `pagination` for the next page. Each team carries its `id`, `name`, `display_name`, `description`, `status` and `managed_by`. Any other field of the record filters the listing as `filter_<field>` or `filter_<field>_<operator>`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
