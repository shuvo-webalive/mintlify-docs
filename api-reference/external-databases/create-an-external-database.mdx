---
title: "Create an external database"
description: "Creates a database with its tables and first records, and returns its name and a message."
openapi: "POST /external_databases"
---

Send the database under `external_database`: a `name` and a `tables` array, where each table has a `table_name`, its `fields` (column names) and its first `records`. Set `replace` to `true` to recreate a database that already exists with the tables in the body. The response holds the `name`, a `message` and `activity_logs` under `external_database`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token). To send a raw JSON body instead of filling in fields, copy the cURL sample and edit its `-d` payload.</Note>
