---
title: "Update records in an external database table"
description: "Changes column values in the rows of a table that match a condition, and returns a message."
openapi: "PATCH /external_databases/{db_name}/update_records"
---

Send the `table_name`, an `update_fields` array of `field_name` and `field_value` pairs, and a `where_condition` with a `field_name`, an `operator` such as `=` and a `field_value`, all at the top level of the body. The response holds a `message` under `external_database`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token). To send a raw JSON body instead of filling in fields, copy the cURL sample and edit its `-d` payload.</Note>
