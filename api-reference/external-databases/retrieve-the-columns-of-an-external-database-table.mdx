---
title: "Retrieve the columns of an external database table"
description: "Returns the columns of one table of a database, as a list under `data`."
openapi: "GET /external_databases/{db_name}/tables/{table_name}"
---

Pass the database `name` as `db_name` and the table's `table_name`. The response has the same shape as the database listing, with the table's columns under `data`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
