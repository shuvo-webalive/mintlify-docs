---
title: "Search an external database table"
description: "Returns the rows of one table of a database, with a count."
openapi: "POST /external_databases/{db_name}/search"
---

Send the `table_name` at the top level of the body. The response, under `external_database`, holds `count`, `limit`, `offset` and a `list` object keyed by table name, where each row maps column names to values. No filter fields are documented yet; with only `table_name`, the call returns the table's rows.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token). To send a raw JSON body instead of filling in fields, copy the cURL sample and edit its `-d` payload.</Note>
