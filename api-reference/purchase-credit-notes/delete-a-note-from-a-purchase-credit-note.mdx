---
title: "Delete a note from a purchase credit note"
description: "Deletes one note from a purchase credit note. Nothing comes back."
openapi: "DELETE /purchase_credit_notes/{purchase_credit_note_id}/notes/{note_id}"
---

Deletes the note, addressed by the credit note's `pcn_` id and the note's `note_` id. The call returns `204` with no body.

<Warning>
  **This call has not been confirmed to work.** It needs a note on the purchase credit note, and adding one needs extra permission.
</Warning>

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
