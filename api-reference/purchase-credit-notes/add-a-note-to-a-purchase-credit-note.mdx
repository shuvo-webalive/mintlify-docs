---
title: "Add a note to a purchase credit note"
description: "Attaches a note, with an optional file, to a purchase credit note."
openapi: "POST /purchase_credit_notes/{purchase_credit_note_id}/notes"
---

Adds a note to the purchase credit note. Send a multipart form with the text as the `note` field and, optionally, a file to attach. Address the credit note by its `pcn_` id. It needs the permission to create purchase credit note notes.

<Warning>
  **This call has not been confirmed to work.** It needs the permission to create purchase credit note notes; without it the call returns `403`.
</Warning>

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
