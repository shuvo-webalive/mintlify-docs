---
title: "Retrieve the root organisation"
description: "Returns the root organisation of your instance under `organization`."
openapi: "GET /settings/organisation"
---

The response holds the root organisation under `organization`, spelled with a z: its name, status, type, contact and address fields, and its `parent_organization`. The root's `type` is `root`, and it names itself as its parent. This record is read only.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
