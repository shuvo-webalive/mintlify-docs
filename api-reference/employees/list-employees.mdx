---
title: "List employees"
description: "Lists employees, one page at a time."
openapi: "GET /employees"
---

Returns one page of employees under `data`, with `pagination` for the next page. Each employee carries its `id`, `code`, `name`, `display_name`, `email_address`, `status`, `contacts` and `custom_attributes`. Any other field of the record filters the listing as `filter_<field>` or `filter_<field>_<operator>`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
