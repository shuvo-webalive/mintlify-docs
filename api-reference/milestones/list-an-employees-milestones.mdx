---
title: "List an employee's milestones"
description: "Lists the milestones that belong to one employee, found by the employee's code."
openapi: "GET /milestones/employee/{employee_code}"
---

Returns the employee's milestones under `data`, with `pagination`. The path takes the employee's `code`; an `emp_` id returns `404`. Any other field of the record filters the listing as `filter_<field>` or `filter_<field>_<operator>`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
