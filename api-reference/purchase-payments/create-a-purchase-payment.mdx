---
title: "Create a purchase payment"
description: "Records a payment to a supplier and returns it under `purchase_payment`."
openapi: "POST /purchase_payments"
---

Records a purchase payment, wrapped in `purchase_payment`. `payment_method_applications` says how it is paid, `purchase_invoice_applications` which invoices it pays, and `credit_note_applications` which purchase credit notes it spends. Paying more than the invoices take raises a purchase credit note.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token). To send a raw JSON body instead of filling in fields, copy the cURL sample and edit its `-d` payload.</Note>
