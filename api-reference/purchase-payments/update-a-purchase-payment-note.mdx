---
title: "Update a purchase payment note"
description: "Replaces the text of a purchase payment note and returns it under `note`."
openapi: "PATCH /purchase_payments/{purchase_payment_id}/notes/{pp_note_id}"
---

Changes the note's text. Send a multipart form with the new text as the `note` field and, optionally, a file to attach. The updated note comes back under `note`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
