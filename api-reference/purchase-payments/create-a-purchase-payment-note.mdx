---
title: "Create a purchase payment note"
description: "Adds a note, with an optional file, to a purchase payment and returns it under `note`."
openapi: "POST /purchase_payments/{purchase_payment_id}/notes"
---

Adds a note to the purchase payment. Send a multipart form with the text as the `note` field and, optionally, a file to attach. The new note comes back under `note`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
