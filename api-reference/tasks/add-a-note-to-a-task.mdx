---
title: "Add a note to a task"
description: "Adds a note, with an optional file, to a task found by its code."
openapi: "POST /tasks/{task_code}/notes"
---

Send a multipart form with the note's text as `note` and, optionally, a `file` to attach. The path takes the task's `code`. The new note comes back under `note`, with its `id`.

<Warning>
  **This call currently returns `409`.** Adding a note to a task fails on the API, so no task note can be created yet.
</Warning>

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
