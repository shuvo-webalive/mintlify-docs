---
title: "Delete a task note file"
description: "Deletes one file attached to a task note; the response has no body."
openapi: "DELETE /tasks/{task_code}/notes/{note_id}/files/{file_id}"
---

Deletes the attachment with this `uuid` from the note. The path takes the task's `code` and the file's `uuid` from the note's file list. A successful delete returns `204` with no body.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
