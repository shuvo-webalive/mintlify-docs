---
title: "Delete a task note"
description: "Deletes one note from a task found by its code."
openapi: "DELETE /tasks/{task_id}/notes/{task_note_id}"
---

Deletes the note with this `id` from the task. The path takes the task's `code`; a `wt_` id returns `404`. After the delete, the task's note list no longer holds the note.

<Warning>
  **This call has not been confirmed to work.** It needs an existing note, and adding a note to a task currently fails.
</Warning>

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
