---
title: "List a reconciliation's refunds"
description: "Returns the refunds included in a reconciliation."
openapi: "GET /reconciliations/{reconciliation_id}/sale_refunds"
---

Lists the refunds in one reconciliation, under `data`. An unknown reconciliation returns `404` with the code `resource_not_found`. Other fields filter as `filter_<field>`, or `filter_<field>_<operator>` with an operator such as `gte` or `contains`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
