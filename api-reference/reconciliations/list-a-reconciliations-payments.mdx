---
title: "List a reconciliation's payments"
description: "Returns the payments included in a reconciliation."
openapi: "GET /reconciliations/{reconciliation_id}/sale_payments"
---

Lists the payments in one reconciliation, under `data`. An unknown reconciliation returns `404` with the code `resource_not_found`. To filter, add `filter_<field>=<value>`, or `filter_<field>_<operator>=<value>` with an operator such as `gte` or `contains`.

<Warning>
  **This call has not been confirmed to work.** Only the `404` for an unknown reconciliation is confirmed; the response body is not documented yet.
</Warning>

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
