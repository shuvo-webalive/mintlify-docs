---
title: "Retrieve the account overview report"
description: "Returns new, cancelled, reactivated and deleted account counts, with the net gain, for each dated entry in a period."
openapi: "GET /reports/accounts/account_overview"
---

The report is under `report.accounts.account_overview`, one entry per `date` with `new`, `cancelled`, `reactivated`, `deleted` and `net_gain`. Set `date_range` to `custom` and pass `from` and `to`; with no parameters, the report covers a default period of 7 dated entries.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
