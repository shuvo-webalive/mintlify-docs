---
title: "Retrieve the invoice overview report"
description: "Returns invoice totals and the amount and count of new, cancelled, reactivated, voided and amended invoices for each dated entry in a period."
openapi: "GET /reports/invoices/invoice_overview"
---

The report is under `report.invoices.invoice_overview`. Each entry has a `date`, an `invoice_total`, and an `amount` and `count` for `new`, `cancelled`, `reactivated`, `voided`, `amended` and `net_gain`. Set `date_range` to `custom` and pass `from` and `to`; with no parameters, the report covers a default period of 7 dated entries.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
