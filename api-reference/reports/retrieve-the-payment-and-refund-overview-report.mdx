---
title: "Retrieve the payment and refund overview report"
description: "Returns the payments and refunds made and deleted for each dated entry in a period."
openapi: "GET /reports/transactions/payment_and_refund_overview"
---

The report is under `report.payment_and_refund_overview`, with a `payments` list and a `refunds` list. Each entry has a `date` and an `amount` and `count` for `new` and `deleted`; a payment entry also has `payment_applied`. Set `date_range` to `custom` and pass `from` and `to`; with no parameters, the report covers a default period of 7 dated entries.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
