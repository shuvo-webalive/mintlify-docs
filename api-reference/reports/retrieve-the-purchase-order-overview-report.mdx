---
title: "Retrieve the purchase order overview report"
description: "Returns purchase order totals and the amount and count of new, cancelled, reactivated, changed and deleted purchase orders for each dated entry in a period."
openapi: "GET /reports/purchase_orders/purchase_order_overview"
---

The report is under `report.purchase_orders.purchase_order_overview`. Each entry has a `date`, a `purchase_order_total`, and an `amount` and `count` for `new`, `cancelled`, `reactivated`, `changed`, `deleted` and `net_purchases`. Choose the period with `date_range`, or `custom` with `from` and `to`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
