---
title: "Retrieve the order overview report"
description: "Returns order totals and the amount and count of new, cancelled, reactivated, changed and deleted orders for each dated entry in a period."
openapi: "GET /reports/orders/order_overview"
---

The report is under `report.orders.order_overview`. Each entry has a `date`, an `order_total`, and an `amount` and `count` for `new`, `cancelled`, `reactivated`, `changed`, `deleted` and `net_gain`. Set `date_range` to `custom` and pass `from` and `to`; with no parameters, the report covers a default period of 7 dated entries.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
