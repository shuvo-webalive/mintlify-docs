---
title: "List pricing periods"
description: "Returns a page of pricing periods under `data`, with paging details under `pagination`."
openapi: "GET /settings/pricing_periods"
---

Lists the pricing periods on the instance. Pass `limit` to set the page size, and while `pagination.has_more` is true pass `pagination.next_cursor` back as `cursor` to read the next page. Other fields filter as `filter_<field>` or `filter_<field>_<operator>`, and `sort` orders the results. Each record's `time_period` reads null here, whatever the record holds.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
