---
title: "Retrieve a gift certificate allocation"
description: "Returns one allocation of a gift certificate, under `gift_certificate_allocation`."
openapi: "GET /gift_certificates/{gc_id}/allocations/{allocation_id}"
---

Pass the certificate's `id` and the allocation's `id`, as the allocations listing gives it. The response holds the same fields an entry in `allocations` has.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
