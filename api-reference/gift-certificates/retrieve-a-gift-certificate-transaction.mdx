---
title: "Retrieve a gift certificate transaction"
description: "Returns one transaction of a gift certificate, under `gift_certificate_transaction`."
openapi: "GET /gift_certificates/{gc_id}/transactions/{transaction_id}"
---

Pass the certificate's `id` and the transaction's `id`, as the transactions listing gives it. The response holds the same fields an entry in `transactions` has.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
