---
title: "Retrieve a purchase order's KPIs"
description: "Returns the KPI figures of one purchase order under `purchase_order_kpis`."
openapi: "GET /purchase_orders/{purchase_order_id}/kpis"
---

Returns the purchase order's KPIs, such as `total_purchase_invoice`, `total_outstanding` and `total_overdue`, under `purchase_order_kpis`. The same figures come with the purchase order as `kpis`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
