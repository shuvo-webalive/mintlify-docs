---
title: "Retrieve a purchase order note file"
description: "Returns the details of one file attached to a purchase order note, under `file`."
openapi: "GET /purchase_orders/{purchase_order_id}/notes/{purchase_order_note_id}/files/{purchase_order_file_id}"
---

Returns one attachment's name, content type, size, `uuid` and link under `file`. Address the purchase order by its `code` and the file by its `uuid`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
