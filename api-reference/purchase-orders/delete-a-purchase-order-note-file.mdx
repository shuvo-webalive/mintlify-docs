---
title: "Delete a purchase order note file"
description: "Removes one attachment from a purchase order note. Nothing comes back."
openapi: "DELETE /purchase_orders/{purchase_order_id}/notes/{purchase_order_note_id}/files/{purchase_order_file_id}"
---

Deletes one file from the note. Address the purchase order by its `code` and the file by its `uuid`. The call returns `204` with no body.

<Warning>
  **Deleting a note file currently fails.** This call currently returns `404` "attachment not found", even for a file the note's file list shows.
</Warning>

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
