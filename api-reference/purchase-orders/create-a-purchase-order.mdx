---
title: "Create a purchase order"
description: "Creates a purchase order for a supplier and returns it under `purchase_order`."
openapi: "POST /purchase_orders"
---

Creates a purchase order from a supplier and its lines, wrapped in `purchase_order`. Name an existing supplier with `account_id`, or send `account` to create the supplier in the same call. A line takes an existing item by `item_id`, or a new one by `item_name` with a price under `item_price_snapshot`. The new order is `active`; send `"draft": true` to create a draft instead.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token). To send a raw JSON body instead of filling in fields, copy the cURL sample and edit its `-d` payload.</Note>
