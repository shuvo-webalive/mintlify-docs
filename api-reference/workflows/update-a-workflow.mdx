---
title: "Update a workflow"
description: "Changes a workflow's fields or moves its status, and returns the workflow."
openapi: "PATCH /workflows/{workflow_id}"
---

Send the fields to change wrapped in `workflow`. A draft can move to active, and an active workflow can move to inactive and back. The updated workflow comes back under `workflow`.

<Warning>
  **This call has not been confirmed.** It needs a workflow made by the create, which currently returns `500`.
</Warning>

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token). To send a raw JSON body instead of filling in fields, copy the cURL sample and edit its `-d` payload.</Note>
