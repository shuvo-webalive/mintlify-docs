---
title: "List a component instance's milestones by settings uuid"
description: "Lists the workflow milestones of one custom component instance, named by the component's settings uuid and the instance's code."
openapi: "GET /workflow/component/{component_uuid}/{component_object_id}/milestone"
---

Unlike `/workflows/custom_components/...`, this route takes the component's `uuid` as the component settings listing shows it, and returns its records under `milestones`, not `data`, with `pagination` beside them.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
