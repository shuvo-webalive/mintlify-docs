---
title: "List a component instance's workflow history by instance code"
description: "Lists the workflow history of one custom component instance, named by its code alone."
openapi: "GET /workflow/component/{component_object_id}/history"
---

Unlike `/workflows/custom_components/...`, this route takes only the instance's `code` and returns its records under `histories`, not `data`, with `pagination` beside them.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
