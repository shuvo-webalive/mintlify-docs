---
title: "Delete a workflow"
description: "Deletes a workflow. Nothing comes back."
openapi: "DELETE /workflows/{workflow_id}"
---

Returns `204` with no body. The workflow is marked deleted, is no longer listed, and a read of it returns `404`. A pre-built workflow cannot be deleted.

<Warning>
  **This call has not been confirmed.** It needs a workflow made by the create, which currently returns `500`.
</Warning>

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
