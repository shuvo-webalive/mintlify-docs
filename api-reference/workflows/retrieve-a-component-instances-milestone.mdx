---
title: "Retrieve a component instance's milestone"
description: "Retrieves one workflow milestone of a custom component instance, by its `wfmi_` id."
openapi: "GET /workflows/custom_components/{component_uuid}/{object_code}/milestones/{milestone_id}"
---

Identify the component by its dashed uuid and the instance by its `code`. Returns the milestone under `workflow_milestone_instance`. A milestone id that does not exist returns `404` with the code `resource_not_found`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
