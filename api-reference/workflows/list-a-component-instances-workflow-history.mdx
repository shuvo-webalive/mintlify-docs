---
title: "List a component instance's workflow history"
description: "Lists the workflow history of one custom component instance, one page at a time."
openapi: "GET /workflows/custom_components/{component_uuid}/{object_code}/history"
---

Identify the component by its dashed uuid and the instance by its `code`. Returns a page of history entries under `data`, with cursor `pagination`. Other fields filter as `filter_<field>` for equality or `filter_<field>_<operator>`, such as `filter_created_on_gte`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
