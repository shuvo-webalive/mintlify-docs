---
title: "List a booking's payments"
description: "Lists the payments made against a booking's invoices, one page at a time."
openapi: "GET /booking/{booking_id}/payments"
---

Returns one page of payments under `data`. Each payment lists the invoices it applies to and how it is applied. Other fields filter as `filter_<field>` for equality and `filter_<field>_<operator>` otherwise.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
