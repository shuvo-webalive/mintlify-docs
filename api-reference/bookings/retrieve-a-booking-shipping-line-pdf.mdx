---
title: "Retrieve a booking shipping line PDF"
description: "Returns the PDF of one shipping line of a booking."
openapi: "GET /booking/{booking_id}/shipping_pdf/{shipping_line_id}"
---

Returns the shipping PDF of the line. Whether the response is the file or JSON links (as Retrieve a booking's PDF links returns) is not documented. Until the line has a generated shipping PDF, the call returns `404`.

<Warning>
  **This call has not been confirmed to work.** The format of a successful response is not documented.
</Warning>

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
