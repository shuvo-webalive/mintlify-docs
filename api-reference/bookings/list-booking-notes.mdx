---
title: "List booking notes"
description: "Lists the notes of every order, one page at a time."
openapi: "GET /booking/notes"
---

Returns one page of notes under `data`, the same list as the order notes listing. There is no per-booking notes listing: `/booking/{booking_id}/notes` is refused. Other fields filter as `filter_<field>` for equality and `filter_<field>_<operator>` otherwise.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
