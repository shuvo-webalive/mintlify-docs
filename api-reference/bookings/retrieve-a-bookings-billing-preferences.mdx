---
title: "Retrieve a booking's billing preferences"
description: "Returns a booking's billing preferences under `order.billing_preferences`."
openapi: "GET /booking/{booking_id}/billing_preferences"
---

Returns the invoice, payment and fulfillment settings of one booking, such as `invoice_mode`, `payment_term` and `billing_period`, under `order.billing_preferences`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
