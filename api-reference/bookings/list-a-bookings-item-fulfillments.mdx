---
title: "List a booking's item fulfillments"
description: "Lists the item fulfillments of a booking, one page at a time."
openapi: "GET /booking/{booking_id}/item_fulfillments"
---

Returns one page of fulfillments under `data`, with a `pagination` block. A booking with no fulfillment returns an empty `data` list. Other fields filter as `filter_<field>` for equality and `filter_<field>_<operator>` otherwise.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
