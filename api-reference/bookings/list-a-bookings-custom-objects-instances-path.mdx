---
title: "List a booking's custom objects (instances path)"
description: "Lists the custom objects orders use, by the `custom_objects_instances` path."
openapi: "GET /booking/{booking_id}/custom_objects_instances"
---

Another path to List a booking's custom objects: it returns the same body, one page under `data`. Other fields filter as `filter_<field>` for equality and `filter_<field>_<operator>` otherwise.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
