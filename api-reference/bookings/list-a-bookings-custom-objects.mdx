---
title: "List a booking's custom objects"
description: "Lists the custom objects orders use, one page at a time."
openapi: "GET /booking/{booking_id}/custom_objects"
---

Returns one page of the custom objects defined for orders under `data`. Read one of them to see this booking's instances of it. Other fields filter as `filter_<field>` for equality and `filter_<field>_<operator>` otherwise.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
