---
title: "Delete a unit of measurement"
description: "Deletes a unit of measurement. A successful call returns `204` with no body."
openapi: "DELETE /settings/uom/{uom_id}"
---

Deletes the unit with that `id`; a later read of it returns `404`.

<Warning>
  **This call has not been confirmed to work.** Creating a unit currently fails; see [Create a unit of measurement](/api-reference/units-of-measurement/create-a-unit-of-measurement).
</Warning>

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
