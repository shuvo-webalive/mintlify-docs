---
title: "List purchase credit note applications"
description: "Returns one page of purchase credit note applications."
openapi: "GET /purchase_credit_note_applications"
---

Lists the purchase credit note applications, one page at a time, under `data`. Each shows the credit note, the payment that spent it, the amount and the remaining balance. Other fields filter the list as `filter_<field>` or `filter_<field>_<operator>`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
