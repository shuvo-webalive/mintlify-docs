---
title: "Delete a return vendor authorization note"
description: "Deletes one note from a return vendor authorization. Nothing comes back."
openapi: "DELETE /return_vendor_authorizations/{rva_id}/notes/{note_id}"
---

Deletes the note, addressed by the return's `rva_` id and the note's `id`. No endpoint lists or creates these notes, so you need the note's `id` already. The call returns `204` with no body.

<Warning>
  **This call has not been confirmed to work.** No endpoint creates or lists a return vendor authorization's notes.
</Warning>

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
