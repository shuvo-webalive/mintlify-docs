---
title: "Delete a draft return vendor authorization"
description: "Deletes a draft return vendor authorization. Nothing comes back."
openapi: "DELETE /return_vendor_authorizations/{rva_id}"
---

Deletes the return vendor authorization, addressed by its `rva_` id. Only a draft can be deleted. The call returns `204` with no body, and reading it afterwards returns `404`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
