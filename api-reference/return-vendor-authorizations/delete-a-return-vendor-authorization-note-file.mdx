---
title: "Delete a return vendor authorization note file"
description: "Removes one attachment from a return vendor authorization note. Nothing comes back."
openapi: "DELETE /return_vendor_authorizations/{rva_id}/notes/{note_id}/files/{file_id}"
---

Deletes one file from the note. No endpoint lists these notes, so you need the note's `id` and the file's `id` already. The call returns `204` with no body.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
