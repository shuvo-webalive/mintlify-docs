---
title: "Create a return vendor authorization"
description: "Creates a return to a supplier for purchase order lines and returns it under `return_vendor_authorization`."
openapi: "POST /return_vendor_authorizations"
---

Creates a return vendor authorization for lines of a purchase order, wrapped in `return_vendor_authorization`. Name the purchase order by its `id`, and each line by its `purchase_order_line` id with the `rva_qty` to return. Send `create_as_draft: true` to save it as a draft.

<Warning>
  **Creating a return vendor authorization currently fails.** This call currently returns `500`.
</Warning>

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token). To send a raw JSON body instead of filling in fields, copy the cURL sample and edit its `-d` payload.</Note>
