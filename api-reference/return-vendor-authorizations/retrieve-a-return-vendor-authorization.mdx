---
title: "Retrieve a return vendor authorization"
description: "Returns one return vendor authorization with its lines under `return_vendor_authorization`."
openapi: "GET /return_vendor_authorizations/{rva_id}"
---

Returns the return vendor authorization with its supplier, purchase order, status, `lines` and `receive_rvas` under `return_vendor_authorization`. Address it by its `rva_` id or its code; both return the same record.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
