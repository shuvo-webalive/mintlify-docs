---
title: "Delete an account group"
description: "Deletes an account group that no account uses."
openapi: "DELETE /settings/account_groups/{account_group_id}"
---

Only a group no account uses can be deleted. A delete returns `204` with no content.

<Warning>
  **This call currently returns `500`.** It fails even for a group just created, so a group cannot yet be removed through the API.
</Warning>

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
