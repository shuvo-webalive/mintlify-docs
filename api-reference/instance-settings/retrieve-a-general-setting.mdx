---
title: "Retrieve a general setting"
description: "Returns one general setting by its `gs_` id within a group."
openapi: "GET /settings/general_settings/{group}/{general_setting_id}"
---

Reads one general setting by its `gs_` id. The other settings responses do not include `gs_` ids. An `id` the group does not hold returns `404`, and an unknown group returns `400`.

<Warning>
  **A successful read has not been confirmed.** No other settings response includes a `gs_` id, so there is no documented way to get one.
</Warning>

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
