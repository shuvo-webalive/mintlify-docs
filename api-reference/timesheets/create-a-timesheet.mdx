---
title: "Create a timesheet"
description: "Records time worked against a booked order line and returns the timesheet under `timesheet`."
openapi: "POST /timesheets"
---

Send the timesheet under `timesheet` with the `sale_order_item` it is for and its `start_time` and `end_time`. The `sale_order_item` is the order line's id with its `ln_` prefix replaced by `soi_`, on an order line that books a labour. The new timesheet comes back under `timesheet`, with its `ts_` id.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token). To send a raw JSON body instead of filling in fields, copy the cURL sample and edit its `-d` payload.</Note>
