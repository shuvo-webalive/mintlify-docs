---
title: "List an RMA's receipts"
description: "Lists the stock receipts of an RMA, one page at a time."
openapi: "GET /return_merchandise_authorisations/{rma_code}/receive"
---

Returns the receipts of returned stock under `data`, each with its `code`, `status` and `quantity_received`. Use the RMA's `code` in the path; its `rma_` `id` returns `404`. Other fields filter as `filter_<field>` for equality and `filter_<field>_<operator>` otherwise.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
