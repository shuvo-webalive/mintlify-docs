---
title: "List return merchandise authorisations"
description: "Lists return merchandise authorisations (RMAs), one page at a time."
openapi: "GET /return_merchandise_authorisations"
---

Returns one page of RMAs under `data`. Each RMA carries its `code`, `status`, `return_status`, `item_count`, account and sale invoice. Other fields filter as `filter_<field>` for equality and `filter_<field>_<operator>` otherwise.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
