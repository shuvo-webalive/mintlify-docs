---
title: "Delete an RMA note file"
description: "Deletes an attachment from an RMA note and returns no body."
openapi: "DELETE /return_merchandise_authorisations/{rma_id}/notes/{note_id}/files/{file_id}"
---

Use the RMA's `rma_` `id` in the path, with the note's and the attachment's `id`.

<Warning>
  **This call has not been confirmed to work.** No endpoint attaches a file to an RMA note.
</Warning>

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
