---
title: "Delete an RMA"
description: "Deletes a draft RMA and returns no body."
openapi: "DELETE /return_merchandise_authorisations/{rma_id}"
---

Only a draft RMA can be deleted. Any other RMA is refused with `400` and the code `stock_committed`.

<Warning>
  **Deleting an RMA currently fails.** This call currently returns `500`, even for a draft RMA, and no endpoint creates an RMA as a draft.
</Warning>

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
