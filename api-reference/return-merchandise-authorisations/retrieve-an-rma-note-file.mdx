---
title: "Retrieve an RMA note file"
description: "Returns one attachment of an RMA note under `file`."
openapi: "GET /return_merchandise_authorisations/{rma_code}/notes/{note_id}/files/{file_id}"
---

Use the RMA's `code` in the path, with the note's and the attachment's `id`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
