---
title: "Delete an account note file"
description: "Removes one attachment from a note."
openapi: "DELETE /accounts/{account_id}/notes/{note_id}/files/{file_id}"
---

Name the attachment by its `uuid`. A delete returns `204` with no content.

<Warning>
  **This call currently returns `404`.** The message is `attachment not found`, even for an attachment that [List an account note's files](/api-reference/accounts/list-an-account-notes-files) shows.
</Warning>

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
