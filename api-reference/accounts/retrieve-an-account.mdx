---
title: "Retrieve an account"
description: "Returns one account with its contacts, addresses, payment methods and billing preferences."
openapi: "GET /accounts/{account_id}"
---

Returns the account under `account`, with its addresses, contacts, payment methods, billing preferences, custom attributes and custom objects inline. Pass the account's `id`, such as `W13ZGY`; its `uuid` returns `404`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
