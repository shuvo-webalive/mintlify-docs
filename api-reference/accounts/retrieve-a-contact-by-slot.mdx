---
title: "Retrieve a contact by slot"
description: "Returns one of the account's contacts, chosen by its slot."
openapi: "GET /accounts/{account_id}/contacts/{contact_type}"
---

Name the contact by its slot, `CONTACT_1` to `CONTACT_5`. The response is the account under `account`, whose `contacts` holds that one contact as an object rather than a list. The `type` the contact reads back as, such as `billing`, and its `con_` id both return `404` here.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
