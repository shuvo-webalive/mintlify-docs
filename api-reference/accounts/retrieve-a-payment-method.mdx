---
title: "Retrieve a payment method"
description: "Returns one of the account's payment methods, under `account.payment_method`."
openapi: "GET /accounts/{account_id}/payment_methods/{payment_method_id}"
---

Returns the account under `account`, with the one method under `payment_method`. A method the account does not hold returns `200` without `payment_method`, not `404`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
