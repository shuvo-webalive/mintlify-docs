---
title: "List an account's purchase payments"
description: "Lists the purchase payments that belong to one account, a page at a time."
openapi: "GET /accounts/{account_id}/purchase_payments"
---

Returns the same purchase payments as the main purchase payments listing, narrowed to one account. The records come under `data`, with `pagination` for the next page.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
