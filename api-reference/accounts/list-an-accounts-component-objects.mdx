---
title: "List an account's component objects"
description: "Lists one component's objects under an account and its child accounts, a page at a time."
openapi: "GET /accounts/{account_id}/component/{component_id}"
---

Name the component by its `cmp_` id. The objects of the account and of its child accounts come under `data`, with cursor `pagination`. The `url` in the response names the component's own objects path rather than the account path.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
