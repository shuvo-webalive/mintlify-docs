---
title: "List an account note's files"
description: "Lists the files attached to one note."
openapi: "GET /accounts/{account_id}/notes/{note_id}/files"
---

Returns the attachments under `data`. Pass an attachment's `uuid` to [Retrieve an account note file](/api-reference/accounts/retrieve-an-account-note-file) or [Delete an account note file](/api-reference/accounts/delete-an-account-note-file).

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
