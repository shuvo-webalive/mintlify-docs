---
title: "List labours"
description: "Lists labours, one page at a time."
openapi: "GET /labours"
---

Returns one page of labours under `data`, with `pagination` for the next page. Each labour carries its `id`, `code`, `name`, `status`, `labour_profile`, `labour_contacts` and availability. Any other field of the record filters the listing as `filter_<field>` or `filter_<field>_<operator>`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
