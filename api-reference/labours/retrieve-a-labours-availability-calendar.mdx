---
title: "Retrieve a labour's availability calendar"
description: "Retrieves one labour's availability calendar."
openapi: "GET /labours/{labour_id}/availability"
---

Returns the labour's calendar under `labour_calendar`, in the same form as one entry of the labour availability list: its schedule, sessions and available and unavailable slots. The path takes the labour's `id` or its `code`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
