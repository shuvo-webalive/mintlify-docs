---
title: "List labour profiles"
description: "Lists labour profiles, one page at a time."
openapi: "GET /labour_profiles"
---

Returns one page of labour profiles under `data`, with `pagination` for the next page. Each profile carries its `currency`, `tax`, `sessions` (with prices, availability and working hours) and the `labours` that use it. Any other field of the record filters the listing as `filter_<field>` or `filter_<field>_<operator>`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
