---
title: "List labours available for booking"
description: "Lists the labours free to book in a time window."
openapi: "GET /labours/available_for_booking"
---

Returns one page of labours under `data` that can be booked between `start_date` and `end_date`, each given as a date and time. Any other field of the record filters the listing as `filter_<field>` or `filter_<field>_<operator>`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
