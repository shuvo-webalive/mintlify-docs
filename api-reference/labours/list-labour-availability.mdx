---
title: "List labour availability"
description: "Lists each labour with its schedule and sessions for a date range."
openapi: "GET /labour_availability"
---

Returns one page of labours under `data`, each with its `labour_profile`, `schedule_list`, `session_list`, `available_list` and `unavailable_list`. Pass `start_date` and `end_date` to set the range. Any other field of the record filters the listing as `filter_<field>` or `filter_<field>_<operator>`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
