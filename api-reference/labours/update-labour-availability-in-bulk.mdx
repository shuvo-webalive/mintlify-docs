---
title: "Update labour availability in bulk"
description: "Sets the availability slots of one or more labours in one call."
openapi: "PATCH /labour_availability"
---

Send `labours`, an array with one entry per labour: its `id` and the slots to set in `labour_availability` or `labour_custom_availability`. Each slot has a `preferred_day`, `start_time`, `end_time` and `available`. When it succeeds, the update returns `204` with no body.

<Warning>
  **This call currently returns `500`.** The bulk availability update fails on the API, so the `204` response below has not been confirmed.
</Warning>

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token). To send a raw JSON body instead of filling in fields, copy the cURL sample and edit its `-d` payload.</Note>
