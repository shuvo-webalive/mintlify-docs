---
title: "Delete a labour profile"
description: "Deletes a labour profile."
openapi: "DELETE /labour_profiles/{labour_profile_id}"
---

Deletes the labour profile with this `id`. Reading the profile afterwards returns `404`. A profile that a booked labour uses cannot be deleted.

<Warning>
  **The success status of this call has not been confirmed.** It is listed as `200`; read the profile afterwards to check that it returns `404`.
</Warning>

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
