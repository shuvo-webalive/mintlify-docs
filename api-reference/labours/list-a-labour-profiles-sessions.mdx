---
title: "List a labour profile's sessions"
description: "Lists the sessions of one labour profile."
openapi: "GET /labour_profiles/{labour_profile_id}/sessions"
---

Returns the profile's sessions under `data`, with `pagination`. Each session carries its dates, `prices`, `availability` and `working_hours`. A profile with no sessions returns an empty `data` list. Any other field of the record filters the listing as `filter_<field>` or `filter_<field>_<operator>`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
