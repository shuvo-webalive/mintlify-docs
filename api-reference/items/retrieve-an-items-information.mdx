---
title: "Retrieve an item's information"
description: "Returns an item's core information, without its sale, purchase or inventory sections."
openapi: "GET /items/{item_id}/information"
---

Returns the item under `item` with its name, type, status, codes, currencies and other core fields. The sale, purchase and inventory sections are left out; read them with their own endpoints.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
