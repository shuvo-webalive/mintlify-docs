---
title: "List items"
description: "Returns a page of items with their core fields and capability flags."
openapi: "GET /items"
---

Returns items one page at a time under `data`, with `pagination` holding `has_more` and `next_cursor`. Set the page size with `limit` and fetch the next page with `cursor`. Filter with `filter_<field>` or `filter_<field>_<operator>`: an unknown field is refused with `400`, and a value the field cannot match returns an empty `data`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
