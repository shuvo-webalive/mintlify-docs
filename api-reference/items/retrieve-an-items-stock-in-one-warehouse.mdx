---
title: "Retrieve an item's stock in one warehouse"
description: "Returns an item's inventory section for one warehouse, named in the path."
openapi: "GET /items/{item_id}/warehouses/{warehouse_name}/inventories"
---

Returns `{id, name, inventories}` under `item`, with `inventories.warehouses` holding only the warehouse named in the path. The warehouse is given by its name, not an id.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
