---
title: "Retrieve an item's inventory settings and stock"
description: "Returns an item's inventory section and its stock per warehouse."
openapi: "GET /items/{item_id}/inventories"
---

Returns `{id, name, inventories}` under `item`, where `id` is the item's `id` code. `inventories.warehouses` lists each warehouse with its quantities on hand, available, on order and promised.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
