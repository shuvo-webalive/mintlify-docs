---
title: "List pro-forma invoices"
description: "Returns one page of pro-forma invoices whose invoice status is active."
openapi: "GET /proforma_invoices"
---

Lists pro-forma invoices one page at a time, under `data`, paged by cursor. Only pro-forma invoices whose invoice status is active are listed. Other fields filter as `filter_<field>`, or `filter_<field>_<operator>` with an operator such as `gte` or `contains`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
