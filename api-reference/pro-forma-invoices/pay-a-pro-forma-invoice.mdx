---
title: "Pay a pro-forma invoice"
description: "Records a payment against a pro-forma invoice and returns the new payment's code."
openapi: "POST /proforma_invoices/{proforma_id}/payments"
---

Takes a payment for the pro-forma invoice from the fields under `payment`. The fields this body takes are not documented yet; the sample shows only the required `payment` wrapper. The response is not the payment itself: it carries `object`, `payment_id` with the new payment's code, and a `message`, under `payment`.

<Warning>
  **This call has not been confirmed to work.** The fields the `payment` body takes are not documented yet.
</Warning>

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token). To send a raw JSON body instead of filling in fields, copy the cURL sample and edit its `-d` payload.</Note>
