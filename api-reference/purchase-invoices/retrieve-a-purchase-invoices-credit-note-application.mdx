---
title: "Retrieve a purchase invoice's credit note application"
description: "Returns one purchase credit note application under `purchase_credit_note_application`."
openapi: "GET /purchase_invoices/{purchase_invoice_id}/purchase_credit_note_applications/{application_id}"
---

Returns the application with the credit note, the payment and the amount under `purchase_credit_note_application`. The application is not checked against the invoice in the path: any application can be read through any purchase invoice that exists.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
