---
title: "List a purchase invoice's credit note applications"
description: "Returns one page of the purchase credit notes spent on a purchase invoice."
openapi: "GET /purchase_invoices/{purchase_invoice_id}/purchase_credit_note_applications"
---

Lists the purchase credit note applications on the purchase invoice under `data`: each one shows the credit note spent, the payment that spent it and the amount.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
