---
title: "List child organisations"
description: "Returns one page of the child organisations on your instance; the root is never included."
openapi: "GET /settings/organisations"
---

Records are under `data`, and the listing pages by cursor. The root organisation is not in this list; read it with `GET /settings/organisation`. Other fields filter as `filter_<field>`.

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token).</Note>
