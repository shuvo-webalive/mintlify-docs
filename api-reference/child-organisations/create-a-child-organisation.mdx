---
title: "Create a child organisation"
description: "Creates a child organisation and returns it under `organization`."
openapi: "POST /settings/organisations"
---

Send the organisation under `organization`, spelled with a z. A create depends on your licence, changes the organisation hierarchy and assigns an existing user. A successful call returns `201`. The fields a child organisation takes are not documented yet.

<Warning>
  **This call has not been confirmed.**
</Warning>

<Note>The SDK samples get their client from credentials your app registers once when it starts, as shown in [Authentication](/authentication#set-up-a-client). To try the call here, click **Try it**, set `host` to your Exsited API host name and paste an access token from [Get an access token](/api-reference/authentication/get-an-access-token). To send a raw JSON body instead of filling in fields, copy the cURL sample and edit its `-d` payload.</Note>
