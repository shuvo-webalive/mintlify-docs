Approval user groups collect the users who can approve transactions. You can list, create, read, update and delete them. This area has 5 endpoints, and all seven SDKs call every one.

## At a glance

| Endpoint | Method | Path | What it does |
| --- | --- | --- | --- |
| [List approval user groups](/api-reference/approval-user-groups/list-approval-user-groups) | <span style={{fontFamily: "var(--font-mono, monospace)", fontSize: "0.72rem", fontWeight: 700, letterSpacing: "0.02em", color: "#0f7b6c"}}>GET</span> | `/settings/approval_user_groups` | Lists the approval user groups on your instance, one page at a time. |
| [Create an approval user group](/api-reference/approval-user-groups/create-an-approval-user-group) | <span style={{fontFamily: "var(--font-mono, monospace)", fontSize: "0.72rem", fontWeight: 700, letterSpacing: "0.02em", color: "#2563eb"}}>POST</span> | `/settings/approval_user_groups` | Creates an approval user group and returns it. |
| [Retrieve an approval user group](/api-reference/approval-user-groups/retrieve-an-approval-user-group) | <span style={{fontFamily: "var(--font-mono, monospace)", fontSize: "0.72rem", fontWeight: 700, letterSpacing: "0.02em", color: "#0f7b6c"}}>GET</span> | `/settings/approval_user_groups/{approval_user_group_id}` | Retrieves one approval user group by its `aug_` id. |
| [Delete an approval user group](/api-reference/approval-user-groups/delete-an-approval-user-group) | <span style={{fontFamily: "var(--font-mono, monospace)", fontSize: "0.72rem", fontWeight: 700, letterSpacing: "0.02em", color: "#c2410c"}}>DELETE</span> | `/settings/approval_user_groups/{approval_user_group_id}` | Deletes an approval user group. Nothing comes back. |
| [Update an approval user group](/api-reference/approval-user-groups/update-an-approval-user-group) | <span style={{fontFamily: "var(--font-mono, monospace)", fontSize: "0.72rem", fontWeight: 700, letterSpacing: "0.02em", color: "#7a5af8"}}>PATCH</span> | `/settings/approval_user_groups/{approval_user_group_id}` | Changes an approval user group's name, display name or description, and returns the group. |

## Before you call

Register your API credentials once when your app starts, as shown in
[Authentication](/authentication). Every SDK sample on these pages then gets its client in one line.
With cURL, send the access token in an `Authorization` header: `Authorization: Bearer $ACCESS_TOKEN`.

## Things to know

- **Writes are wrapped in `approval_user_group`.** One group comes back under the same key, and `name` is required to create one.
- **An update changes the name, display name or description.**
- **Approval user group ids start with `aug_`.** A deleted group returns `404`.
- **Listings page by cursor.** Records sit under `data`; pass `pagination.next_cursor` as `cursor` to read the next page, and stop when `pagination.has_more` is `false`.
