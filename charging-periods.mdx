A charging period is a settings record linked to a time period. You can list, create, read, update and delete charging periods. This area has 5 endpoints, and all seven SDKs call every one.

## At a glance

| Endpoint | Method | Path | What it does |
| --- | --- | --- | --- |
| [List charging periods](/api-reference/charging-periods/list-charging-periods) | <span style={{fontFamily: "var(--font-mono, monospace)", fontSize: "0.72rem", fontWeight: 700, letterSpacing: "0.02em", color: "#0f7b6c"}}>GET</span> | `/settings/charging_periods` | Returns a page of charging periods under `data`, with paging details under `pagination`. |
| [Create a charging period](/api-reference/charging-periods/create-a-charging-period) | <span style={{fontFamily: "var(--font-mono, monospace)", fontSize: "0.72rem", fontWeight: 700, letterSpacing: "0.02em", color: "#2563eb"}}>POST</span> | `/settings/charging_periods` | Creates a charging period and returns it under `charging_period`. |
| [Retrieve a charging period](/api-reference/charging-periods/retrieve-a-charging-period) | <span style={{fontFamily: "var(--font-mono, monospace)", fontSize: "0.72rem", fontWeight: 700, letterSpacing: "0.02em", color: "#0f7b6c"}}>GET</span> | `/settings/charging_periods/{charging_period_id}` | Returns one charging period by its `id`, under `charging_period`. |
| [Delete a charging period](/api-reference/charging-periods/delete-a-charging-period) | <span style={{fontFamily: "var(--font-mono, monospace)", fontSize: "0.72rem", fontWeight: 700, letterSpacing: "0.02em", color: "#c2410c"}}>DELETE</span> | `/settings/charging_periods/{charging_period_id}` | Deletes a charging period. The response has no body. |
| [Update a charging period](/api-reference/charging-periods/update-a-charging-period) | <span style={{fontFamily: "var(--font-mono, monospace)", fontSize: "0.72rem", fontWeight: 700, letterSpacing: "0.02em", color: "#7a5af8"}}>PATCH</span> | `/settings/charging_periods/{charging_period_id}` | Changes the fields you send on a charging period and returns it under `charging_period`. |

## Before you call

Register your API credentials once when your app starts, as shown in
[Authentication](/authentication). Every SDK sample on these pages then gets its client in one line.
With cURL, send the access token in an `Authorization` header: `Authorization: Bearer $ACCESS_TOKEN`.

## Things to know

- **`name`, `display_name` and `time_period` are required on a create.** `time_period` is the time period's `tp_` id.
- **A read returns `time_period` as an object.** It holds the time period's `id`, `name`, `object` and `href`.
- **A charging period `id` starts with `cp_`.**
- **Listings page by cursor.** Pass `limit` for the page size, then pass `pagination.next_cursor` back as `cursor` while `pagination.has_more` is true.
- **A delete returns `204` with no body.** Reading the charging period afterwards returns `404`.
